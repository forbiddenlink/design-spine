# Phase decisions

The user's continuation approved accessibility checks, mixed-resolution profiling and repeated-session recovery. Source work stayed within those tasks on design/upgrade. Existing example data, captured originals and baselines were untouched.

Measured per-image synchronous work delayed saves by seconds, so native comparison moved to a serialized background worker without resizing evidence or changing thresholds. Per-request workers and reuse without collection increased end-of-trial memory materially. Preserved those intermediate measurements, reused one worker, and released decoded buffers off-thread after completion. Final foreground latency improves; total throughput remains variable and peak memory is unmeasured. Idle lifetime is finite and restart was exercised.

The route hover contrast failed at 4.495:1. Darkening the existing accent slightly fixes the numeric failure. All link/count states are measured after transitions settle and after moving each mobile link into view. Axe's remaining offscreen/short-text incompletes remain recorded.

VoiceOver activation did not succeed through native controls. No permission escalation or AppleScript setting change was attempted. Only accessibility-tree inspection is claimed. Forty-eight interrupted-save cycles plus queued-save/expiry/reload checks are finite stress, not a multi-hour soak.

Source CLI preview, unit tests, typecheck, lint, HTML build and Lighthouse pass. CLI compilation succeeds, but its executable cannot resolve external dependencies in the embedded filesystem. Record packaging as blocked instead of implying a standalone artifact works. No merge, deploy, new service, migration or deletion.
