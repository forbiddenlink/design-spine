## Core checks

- Axe: 0 violations on UI (light, dark, 390, lightbox open) and site (light, dark, 390). Only the 320px site run reported A11Y-002.
- Skip link present on UI (`a.skip`, first tab stop). Site has no skip link, but its nav has 7 stops; Low, not filed.
- Headings: UI has a single h1 and h2s; site h1 then h2 sections (the "Try a review" h2 sits inside the "Reject a frame yourself" section, fine).
- Lightbox (`<dialog>`, `:modal` true): focus lands on Close, Tab cycles inside, Escape closes. Native controls throughout, labels present, `aria-pressed` on toggles, live regions for save status.
- Failure states announce: save failure shows "Changes could not be saved..." in `#save-status` (role=status) with a retry button (`shots/ui-save-failure-1440.png`).
- Reduced motion: site runs 7 animations (strip-slide, draw, appear) normally and 0 under `prefers-reduced-motion: reduce`; UI has none at rest and gates motion behind `no-preference` (`review.css:1359`). Not played through every interaction.
- Dark mode: axe passes in both; APCA was not computed (NOT COVERED).
- Overflow: none at 390 on either surface.
- No third-party accessibility overlay on either surface.
- Colour-only information: tile decisions use border colour plus a text label (Approved/Rejected/Pending) in the card header.

Legal risk: Low. Basis: local developer tool and a marketing page, 0 axe findings, one A-level gap at 320px (A11Y-002) and a 2.1.4 gap (A11Y-001). EAA scope not assessed (see `gdpr`).

Quick wins: A11Y-002, A11Y-004 `#copy` padding. Design decision needed: A11Y-001 (shortcut toggle), A11Y-003 (transcript).
