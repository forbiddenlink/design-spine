# Functional review coverage

Scope: Liz-owned Design Spine only, branch design/upgrade. Expected behavior comes from docs/USAGE.md, CLI descriptions, existing tests and visible review controls. Existing example captures/reviews/baselines are excluded. No production systems, secrets or paid provider requests were used.

Product: a Bun/TypeScript local design gate for Next.js projects. The operator drafts capture routes, records screenshots and diagnostics, optionally requests Claude critique, reviews evidence, explicitly approves baselines and runs a pixel/lint gate. There is one product page `/` with review, viewer and recovery states. The three demo pages are intentionally imperfect capture fixtures. No accounts, role hierarchy, database, billing or scheduled jobs exist. Website session input is an optional Playwright storageState file; local runs/reviews/critique/baseline/lint JSON and PNGs are the data model.

Baseline: Node 22.23.1, Bun 1.3.13; 41 tests passed. Final: 73 tests in 12 files pass, typecheck passes, lint exits 0 with one pre-existing warning, both entry-point builds pass. New controls use native HTML/SVG and existing data, with no dependency/schema migration.

Control accounting: export, every filter, search, route index, both page navigations, next pending, preview scrolling, inspect, diagnostic disclosure, approve/reject, note/retry, viewer navigation/size/download/close/backdrop, mode selection, blank-region toggle/jump, refresh and skip link are accounted for above. UI request interception is used for deterministic loading/save/error tests; server/workflow checks separately verify real files and responses.

Limitations: no guarantee for arbitrary imported/malformed manifests, multiple independent CLI writers, extremely large mixed-resolution baseline libraries, provider authentication/rate limits/timeouts, real browser history across reloads with unsaved drafts, physical low-end devices or manual assistive technology. Current comparison processing yields between images, but each PNG decode/diff remains synchronous. No universal correctness claim.
