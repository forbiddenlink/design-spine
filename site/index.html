Most UI gets checked in one state: the happy path, at desktop width, in light mode. Coding agents make it worse. They build screen by screen and never open the 390 pixel dark-mode empty state.

Design Spine makes the whole matrix visible, checks each frame automatically, and turns "someone looked at it" into a record your CI can enforce.

How it works

  1. Plan the matrix

    Reads your app/ folder and drafts every route with the states it can have. Not on Next.js? spine plan --sitemap reads a sitemap instead.

    spine plan
  2. Capture every frame

    Each route in each state, at 390 and 1280, in light and dark. Empty and error states come from mocked responses, not a seeded database.

    spine capture
  3. Review the contact sheet

    Approve or reject each frame with a keystroke. Leave a note pinned to the exact spot.

    spine review
  4. Keep what you approved

    Approved frames become baselines. Nothing becomes a baseline without a person.

    spine approve
  5. Gate the next change

    CI fails when a frame drifts from what you approved.

    spine diff

Checked on every frame

Checks flag frames for your attention. They never approve anything.

  • Horizontal overflowThe page scrolls sideways on a phone.
  • Console and page errorsAnything the browser logged as an error while rendering.
  • Blank regionsA card or section that rendered with nothing in it.
  • Covering overlaysCookie banners and chat widgets sitting on top of content.
  • Broken images and clipped textMissing assets and labels cut off by their container.
  • HTTP errors and redirectsA route that 404s or bounces to login.
  • Accessibility scanOptional axe pass on every frame.
  • Second opinionOptional Claude vision critique, using your app's own design notes.

Moving from Lost Pixel

Lost Pixel's page shots map onto routes and states. One command reads your config and writes the manifest.

npx spine import lost-pixel   # reads lostpixel.config.ts/js, writes design-spine.json
npx spine doctor
npx spine capture --start "npm run start"

The import notes anything without an exact equivalent, such as per-page thresholds. Storybook and custom shots are not imported.

Try it on your app.

# start your app locally, then:
cd your-next-app
npm install -D design-spine
npx playwright install chromium
npx spine plan
npx spine capture
npx spine review

The npm package bundles Bun. Route discovery from the Next.js App Router or a sitemap; Chromium captures. Full setup on GitHub.
